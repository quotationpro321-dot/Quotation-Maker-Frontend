This folder contains airline logo PNGs keyed by IATA code (lowercase filename, e.g. qr.png).

Assets were fetched from the public Kiwi.com airline icon CDN
(https://images.kiwi.com/airlines/64x64/<IATA>.png) and committed here so Next.js can serve
them from /airlines/*.png without depending on that host. Airline marks remain their owners’
trademarks; use only in line with your product’s licensing needs.
